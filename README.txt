FROMAGO · Nuestro plan

Contenido:
- index.html: aplicación
- manifest.webmanifest: instalación como PWA
- sw.js: funcionamiento offline
- icon-192.png / icon-512.png: iconos

Uso rápido:
1. Publica esta carpeta en cualquier hosting estático HTTPS (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Abre la URL en el móvil.
3. iPhone: Compartir > Añadir a pantalla de inicio. Android/Chrome: menú > Instalar aplicación.

Los favoritos se guardan en cada dispositivo. “Compartir plan” genera un enlace que transporta las selecciones de ambos usuarios; no hay sincronización en tiempo real entre teléfonos.
